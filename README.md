# VRChat Room & Avatar Pipeline Project

VRChat 개인 월드와 아바타를 제작하면서
Blender → FBX → Unity → VRChat 파이프라인을 학습하는 프로젝트입니다.

## Goal

- Build a simple VRChat room
- Create and import Blender assets
- Create a basic humanoid avatar
- Test the VRChat production pipeline
- Record optimization and troubleshooting

## Week 1 - Room Prototype

### Completed

- Created a VRChat World project with VCC
- Built a room prototype using Unity primitives
- Added floor and wall colliders
- Configured the world spawn
- Passed VRChat SDK world validation
- Successfully built the world

### Troubleshooting

**Problem:** Build & Test succeeded, but the VRChat client was not installed.

**Solution:** Install the VRChat client before local world testing.
